# 动作、受击与 VFX

## 参考到动作

用户提供视频链接时，先按 [视频参考获取与检查](video-reference.md) 解析来源、分 P 和时间范围，复用已有媒体或取得可查看的视频；获取失败时按该文档切换路径。

实际观看选定片段，先描述身体实际运动，再判断是肘击、爪击或侧踢，避免先入为主。不能只根据标题、招式名称或已有资源记录推测原片；资源中的时间定位不等于重新看清参考。

新做参考连击时，制作前按真实攻击动作建立对照表；局部修正只补受影响动作。动作数量与伤害段数分开：一次连续攻击或一次喷发可以承载多次伤害，不能按伤害次数重复挥拳或拼接姿势。每项结论应能指回具体时间或画面：

| 项目 | 要记录的证据 |
|---|---|
| 时间 | 准备、启动、加速、接触、随动与衔接的参考时间 |
| 动作性质 | 攻击方式、接触部位、目标和方向；“突进、上冲、下落”只描述位移，不代替肩击、跃起上勾拳等动作辨认 |
| 出招肢体 | 左右手脚、拳／肘／脚等接触部位，是否换手 |
| 身体变化 | 支撑脚与重心移动、骨盆和胸腔转动、肩肘传力、非攻击手的配合、起跳与空中转体及落地衔接 |
| 攻击路线 | 向前、向下、侧向或由下向上，肢体如何伸展 |
| 表现对应 | 实际命中位置、受击方向、VFX 与声音时点 |
| 伤害映射 | 每个完整攻击动作承载哪些伤害事件，不用事件段数决定动作数量 |
| 判断把握 | 区分参考画面事实、R15 等骨架适配处理、遮挡／歧义，给出依据画面 |

同时看正常速度、慢放与“准备—发力—接触—收势—下一击衔接”的连续过程。快速动作按原片帧率检查接触前后，不能只靠每隔固定时间抽取的缩略图，避免跳过决定动作性质的帧。火花遮挡时结合前后轨迹分析，必要时找同招其他视角；仍不确定且会改变制作方向的疑点集中向用户说明，不把推断写成确认，也不要求用户逐击代做分析。

用户要求还原时保留确认的动作顺序和发力关系；参考中的演出减速按下文适配，不把原视频片段的播放时长直接当制作时长。明确要求删减的动作同步清理相关标记、时长、挂点和配置。

文字拆解应能解释身体如何完成每一击，而非只有招式名称或效果概括。先交付带参考时间与画面的动作分析；获制作授权后，先做无特效、固定镜头的连续动作，从侧面、斜前方等有用角度检查常速和慢放，再接回完整表现。会改变制作方向的歧义先解决，已授权范围内无需为每个步骤重复询问。

## 全身发力与连续运动

先明确支撑与重心，建立骨盆、胸腔、肩肘和攻击肢体的传力关系，再安排拳脚轨迹。非攻击手应服务于平衡、防护或转体，不能随意当装饰摆放。腾空动作需要连续的蹬地起跳、身体上升、空中转体与落地配合，不能只整体抬高角色再摆举拳姿势。

对照准备、启动、加速、接触、随动及转入下一动作的完整过程，检查中间帧和发力先后。关键姿势与插值是制作工具，不能仅因手脚起点、终点接近参考就认定动作成立。上一击的余势应能进入下一击；参考在空中完成收拳与转体时，不能凭空插入落地后再蓄力的停顿。

IK、两段式 IK 和末端落点约束只辅助接触、脚底及局部姿态校正，不代替全身动作设计。不能为满足拳头贴地或直线路径，强迫腰、膝、肩迁就落点，形成跪下撑地、侧倒或单纯摆臂。先保证动作性质与整体发力成立，再校正接触；检查骨架比例、脚底、落地、接触位置和目标体型。动画、特效和伤害职责分开，伤害仍由业务决定；连续播放不累计世界位置漂移。

收拳和回稳应能解释其作用，完成后自然结束或衔接下一招。不要用冻结末帧、额外待机、等待目标演示复位填补尾段。先检查播放交接，再按需要调整首尾关键帧；不要把有设计目的的蓄势或业务保持一律删掉。

## 动作成立后再强化表现

调整顺序：动作性质与左右肢体 → 支撑、重心与全身传力 → 挥击路线及接触校正 → 时间节奏与幅度 → VFX、受击、声音和镜头匹配。先隐藏特效对照参考，确认肘击可见屈肘下压、侧踢可见侧身支撑和伸腿、双手交替确实由不同手完成，再检查完整效果。不能用更大火焰掩盖错误动作，也不能用正确命中次数代替逐击画面对照。

准备与命中应有有意义的空间差异，但不是每击都大幅蓄力。结合参考表现准备可读、出手加速、接触顿挫和衔接恢复，避免全程匀速摆动或每击硬停。上一击收势可以成为下一击前摇，不逐击退回同一准备姿势。

检查上一轮末击到下一轮首击的实际间隔；循环间隔设为零仍可能有长空档，需结合尾段和起手观看，不能仅凭时间差判定生硬。已确认总时长和击数作为基线；参考证据需要改变时说明差异和业务影响，不为了加大动作擅自改变输出节奏。

## 参考演出与项目节奏

识别参考中的整体演出减速、定格与结算等待；项目没有对应机制时不照搬这些时长，按正常发力和衔接重排时间。保留必要蓄力、出手快慢对比与接触顿挫，不把所有重复帧当冗余删除，也不简单将整段等比例加速。删减演出停顿与删改攻击动作应明确区分。

用户未限定时长或已撤销旧限制时，以正常动作过程决定时长，不为凑秒数拉长姿势或收势；单个案例的最终时长不是后续招式标准。仍有效的时长、击数要求继续遵守，确需变更先说明差异与业务影响。角色完成必要回稳即可结束，粒子余效独立消散，不让角色停在那里等特效消失。

## 受击

首击前不播放受击姿态。按实际命中触发，保证后续反应与实际播放节奏一致；基础连击适配支持的攻速，当前项目奥义按固定常速同步。轻击优先复用已有资源，方向和力度不足时补片段。连续受击避免突然回正或重复举手。

抓持、失衡、倒地等需要对位时，先核实项目支持并定义接入方式。普通反应和业务倒地职责见 [项目适配](project-integration.md)。

《格斗之王》当前项目的基础连击与奥义，最后一击受击动画必须保持站立，不能制作倒地、击飞或起身；普通受击默认保持站立。可通过后仰、躯干震动与短暂失衡表达终击力度。未致命时恢复继续战斗；致命时由业务在规定时机接管倒地，受击末姿态需自然衔接。不得只以“没有重复倒地”代替这一动作制作要求；明确扩展倒地／击飞玩法时再按新需求设计。

## 选材与效果层次

优先查看工具箱和已认可招式的成套效果，先并排比较，再接入动作。完整检查蓄势、拳路、接触、贴体与终结余效，避免只复制手部效果。

保留成熟素材的轮廓和层次，优先调整挂点、比例、方向、颜色及触发时机。没有合适素材时说明缺口并按任务范围处理，不把用户要求复用擅自改成从零制作。

成套复用不等于保留素材包所有阶段。按参考与确认方案逐项筛选，清理未经确认的起势闪光、光环等遗留内容；例如素材自带 `Start` 不能成为新增起势的理由。《格斗之王》要求的终极技统一发动属于已确认内容，即使选取的参考片段未展示也必须保留。基础连击是否需要起势按参考与确认方案确定，不把某一套无起势推广为所有基础连击的禁令。

基础连击清晰紧凑，奥义按阶段增强，最强峰值留给确认的终结。检查人物和接触点是否被白光遮住、火焰是否失去轮廓、贴图是否出现黑色方片，不能单靠增加粒子数判断增强有效。

## 当前项目终极技起势

《格斗之王》每个奥义／终极技的完整制作，从计划阶段分别列出统一发动、角色专属蓄力和正式出手。统一发动包含项目已认可的起势 VFX 与启动提示音；手部聚电、蓄火或元素声只属于角色准备，不能据此报告统一起势已完成。

优先复用项目现有起势预制、提示音和播放逻辑，保持统一辨识度，再接角色专属准备。发动到蓄力、出手自然衔接，不为补起势擅自改变已确认的总时长、击数与伤害节奏；确需调整时先说明差异及业务影响。

每次发动按设计触发统一起势一次，不随逐击命中重复触发。沿用项目事件与动画进度同步方式，当前项目奥义按固定常速同步，无需加速适配或校验；中断、重播和退出时取消旧轮尚未触发的事件，停止持续发射并正确收尾。普通预览的基础起势与镜头演出分开控制，具体见 [镜头接入](camera-integration.md)；声音要求见 [音效接入](audio-integration.md)。

## 挂点

| 类型 | 运行时位置 |
|---|---|
| 拳路、手部火焰、出招气流 | 出招者对应部位，按局部偏移与角色比例适配 |
| 爪痕、火花、命中爆燃 | 受击者实际命中位置，方向与攻击一致 |
| 贴体火焰、余效 | 受击者对应部位 |
| 地面冲击、地裂 | 实际地面位置，考虑朝向和高度 |

检查缩放、转向和移动后的结果，避免将原尺寸或演示世界位置写死。

更换出招肢体时，同步核对动画、轨迹挂点、命中特效、受击方向及声音时点与位置，不能只把一组特效移到另一只手。接触算法应覆盖实际攻击区域，低踢不能被只在头和躯干选点的逻辑强制映射到上身；肘部、手部与脚部的出招挂点也应与动作一致。

## 自然收尾

- 粒子和拖尾优先通过寿命、透明度等预制属性实现消散。
- 光束整条随时间渐隐需要相应播放控制；不能用单纯延迟关闭冒充渐隐。
- 正常结束、打断、同招重播时，停止旧触发与旧轨迹生成，解除旧监听；已产生余效有机会结束，再由回收机制释放。
- 回收期限覆盖可见尾部。检查实际中间画面，不以“最终关闭”或“实例最终为零”代替自然收尾验收。
