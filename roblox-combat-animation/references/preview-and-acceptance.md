# 预览与验收

## 预览组织

资源保存在独立待验收目录。基础连击与奥义可各用一组攻防角色场景内循环，提供播放、速度和间隔设置，允许自由查看，不占用其他游戏流程。

预览采用可迁入业务的受击、挂点和表现播放方式。演示站位、循环、模拟致命、展示地面、独立预览机位和镜头开关分开管理；已确认的招式运镜仍须迁移并与正式玩法共用计算，见 [镜头接入](camera-integration.md)。若项目启动会移除原地面，应确保验收地面在运行时有效，不能只看编辑模式摆放。

奥义镜头预览开关默认关闭；关闭时不接管相机、不修改 FOV、不运行镜头更新。开启时关键动作和双方保持入画，避免进出镜头扫过空场。途中关闭、停止、删除预览脚本都应释放控制并恢复接管前相机状态；验证实际销毁路径，不能仅因为写了回调就认为有效。

## 测试范围与业务副作用

按 [迁移阶段](project-integration.md) 选择入口：验收副本检查独立预览；正式资源迁移在临时角色上调用正式模块和资源；装备／玩法接入验证真实流程；线上发布另按授权处理。不能为满足真实入口测试而擅自接装备或扩大交付范围，也不能将资源测试报告为玩法已接入。

运行战斗测试前核对奖励、存档及进度写入。优先使用运行同一份战斗代码的隔离测试环境，在测试边界阻断奖励和持久化请求，并确认隔离实际生效；保留待测动画、镜头、致命和退出逻辑。仅修改临时血量不代表副作用已隔离，还要核对运行时是否使用已缓存配置。

若意外触发奖励或其他写入，停止继续扩大副作用、如实报告已知影响，再改用隔离方式测试。未经核实不能宣称数据已恢复；清理测试副本与恢复相机不等于撤销玩家奖励，也不应擅自修改存档抵消。

## 验收矩阵

按本次范围选择检查项。完整制作默认以 1 倍和 1.75 倍速各至少 10 轮为基线；同时覆盖实际支持的速度范围。该数字是工作基线，不是所有项目的固定参数。

| 类别 | 观察与证据 |
|---|---|
| 参考与动作 | 顺序、接触帧、落脚、发力与收尾符合确认方向，无无意义定格 |
| 首击及同步 | 首击前受击轨道不接管；逐击受击、特效与声音同步，次数无漏发或重复 |
| 循环 | 观看尾到首交接，覆盖零间隔和有间隔；无姿势跳变或累计位置漂移 |
| 体型与站位 | 缩放、朝向、距离改变后挂点、声音来源和接触位置仍正确 |
| 非致命 | 普通受击、终击后可以按业务恢复或继续承接攻击 |
| 致命 | 基础不同击次、奥义中途与末击、适用的 QTE 路径；倒地、落地反馈和完成通知不重复 |
| 中断与回收 | 停止、换招、同招重播、退出后不补发旧事件，余效和短音自然收尾，实例回到基线 |
| 镜头 | 完整节拍、加速与连续换招，致死到 KO、超时及退出恢复；无争抢、突跳或残留偏移；手机横屏、窄画幅和大体型取景清楚，推拉仍可辨识 |
| 声音 | 默认设置、音效开关、正式听距、分角色归属和实际试听；换招不截断应保留尾音，详见音效参考 |
| 正式资源 | 正式 ID、配套起势和映射可用，调用正式模块且不依赖验收目录；完整迁移已确认的声音和镜头 |
| 玩法入口 | 仅在本轮接入范围内验证训练、战斗真实流程与配置引用、数值依赖 |
| 旧招回归 | 共用模块或相机逻辑改变后，回归受影响旧招的命中、声音、镜头和收尾 |

视觉连续性与声音听感必须分别观察。不能用命中计数正确、轨道正常结束或对象最终回收来代替观感。正式渐隐要验证中间过渡帧，不能只看最终关闭。

## 完成报告

记录所测版本／位置、模式、速度、循环次数、触发分支、观察结果及未验证项。明确区分副本模拟、正式资源测试、真实玩法验证和用户观感认可；隔离测试说明哪些副作用被禁用，不能将模拟回调计数当作真实奖励链路已验证。

给出可编辑资源位置、正式迁移所需引用和已知约束。已制作的验收动画不等于已发布可供正式运行使用的动画；Studio 正式资源修改不等于线上发布。任务到达已授权交付范围即可报告，不自动推进下一阶段。
