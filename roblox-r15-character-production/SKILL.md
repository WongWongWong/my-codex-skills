# Roblox R15 人形制作

## 确认用途和底模

- 从本次需求确定角色用途、视觉参考、体型和场景尺度。需要复用动画或进入已有系统时，先核对目标模板、角色入口和需要播放的动作。
- 有指定模板时，检查其结构并在副本上制作。没有指定模板时，优先复用项目里已验收的兼容 R15 底模，或用 Studio Rig Generator 建立标准底模。按当前项目确认资产路径、命名和交付位置。 [Rig Generator](https://create.roblox.com/docs/studio/rig-builder)

## 选材和试装

- 先看项目已验收的模型和外观件，再按需求搜索 Toolbox 或 Marketplace。适合的 R15 整模可以复用。R6 候选可拆取合适的服装、发型和网格配件，在 R15 底模上重新试装。
- 在隔离的预览副本上检查第三方资产。导入后先检查附带脚本和依赖，避免执行第三方代码。纯模型交付仅保留骨架和外观件，项目自有的角色行为按接入约定处理。 [Toolbox](https://create.roblox.com/docs/projects/assets/toolbox)
- 优先保留参考中影响角色辨识度的轮廓、服装和配件。缺件时记录差异，角色身份或关键造型需要变更时按本次约定处理。经典平面脸优先使用适合头型的正面脸贴。动态头和遮脸造型按设计验收。

## 验收和替换

1. **骨架。** 检查 `Humanoid.RigType` 为 `R15`，15 个标准身体部件和独立的 `HumanoidRootPart` 齐全。确认身体部件经正确的关节连接到根部，关节实现以目标模板和动画系统为准。逐个检查配件的挂点或绑定目标。 [Humanoid](https://create.roblox.com/docs/reference/engine/classes/Humanoid)
2. **外观。** 在 Studio 看正面和侧前方。长发、披风或背饰加看背面。确认预期的脸、上下装和材质实际显示，配件没有悬空或明显穿插，比例、脚底高度和朝向符合用途。贴图字段已赋值只能证明引用存在。遇到空白、错误贴图或脸被挡住时，分别检查加载情况、头部兼容性和遮挡。
3. **动画。** 需要兼容现有动作时，在获准的测试环境通过目标项目的动画入口播放代表性动作。按用途选择待机、移动、攻击或受击，观察躯干、四肢、配件和服装随动。编辑模式预览和运行时播放分别记录。
4. **批量与交付。** 先制作并验收一个有代表性的样板，再扩展同类角色。逐个验收成品，候选通过适用检查后再替换已有模型。交付时列明成品位置、缺件或造型差异、已完成的检查和待验证项。
