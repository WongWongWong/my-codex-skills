# PNG 遮挡面板与分层进度条

仅在采用“透明开口面板覆盖矩形进度条”时读取。本参考记录构造方法与条件，不规定所有 UI 的外观、进度方向或损失表现。

## 先确定形状要求

固定面板负责槽位的外轮廓，矩形填充负责进度。外轮廓可以斜切，槽内活动端仍可为竖直边；用户接受这种效果时无需增加随动斜端片。若活动端也必须斜切，再选择相应方案，不能把固定遮挡图描述成能自动改变活动端形状。

这是图片覆盖产生的视觉遮挡，不是对任意底图应用 Alpha 蒙版：面板遮挡区必须有足够的不透明度和覆盖面积。面板外部仍透明时，底层矩形不能伸到那些区域。

## 素材与槽口校准

1. 面板具有真实透明的开口，开口周围负责遮挡，外围按美术需要透明。检查 Alpha 数据，不能只凭预览背景颜色判断。面板 ImageLabel 的 BackgroundTransparency 设为 1，避免实例自身底色堵住透明孔；不承担底色的父容器也应透明。
2. 记录整图尺寸 `W × H`、孔洞边界和底层矩形 `slotRect=(x,y,w,h)`。孔洞的斜角周围必须有足够遮挡区；没有留足空间时修正面板，不靠新增复杂运行时裁切掩盖资源问题。
3. 底层矩形可略微越过孔洞边界，以覆盖抗锯齿过渡；余量按素材尺寸和实际显示测试决定，不固定复制某次使用的像素数。检查四边、斜角及附近飞白是否漏色。
4. 当面板整图正好铺满同一个父容器，且底层槽位容器 AnchorPoint=(0,0) 时，可映射为（这里的槽位容器不是内部居中锚点的 Fill／Loss／Settling）：
   - `Position = UDim2.fromScale(x/W, y/H)`
   - `Size = UDim2.fromScale(w/W, h/H)`
5. 上述换算要求坐标属于同一张完整画布，并包含其透明留白。若保留槽位容器的其他锚点，Position 需计入该锚点乘以容器尺寸的偏移。如果使用图集裁切、九宫格或 `Fit` 留白，先换算到实际可见图像区域，不直接套整图比例。
6. 将遮挡图片与内部布局作为一个大区域统一缩放。用色差明显的满槽／空槽底色检查边缘，再在真实场景中确认近乎不透明的边缘是否仍有可见漏色。

## ImageRectOffset／ImageRectSize 的职责

这两个属性选取纹理中的矩形区域，适合图集或局部裁切；它们不会把其他 GUI 对象裁成斜边，也不是 UI 元素的显示大小。尺寸与偏移以纹理像素为依据，使用前核对引擎实际使用的图像及尺寸，不直接复制屏幕上的像素宽高。

使用整张独立面板时，通常保留 `ImageRectOffset=Vector2.zero`、`ImageRectSize=Vector2.zero`，避免继承旧图集参数。

设置后图片消失时，按当前实例检查：资源是否加载、裁切矩形是否越界或落在透明区、大小／偏移是否对应当前图片，再查可见性、透明度、父级裁切和层级。不要直接换资源 ID 掩盖裁切参数错误。

属性说明以 Roblox 当前 [ImageLabel 文档](https://create.roblox.com/docs/reference/engine/classes/ImageLabel) 为准；平台导入或缩放行为不确定时先查证。

## 层级与固定位置方案

以下适用于从左侧向右显示剩余量、需要“本套损失＋上一套收束”的方案。反向填充、居中填充或其他语义应另行匹配，不机械套用。

由上到下的视觉顺序：

1. 动态名字、数值等需要显示在面板上的文字。
2. 带透明槽口的面板。
3. 当前真实进度 Fill。
4. 本套动作开始时快照 Loss。
5. 上一套结束后收束的 Settling。
6. 空槽背景。

三条使用同一个 Track 坐标系，`AnchorPoint=Vector2.new(0,0.5)`，`Position=UDim2.fromScale(0,0.5)`。位置保持不变，各条高度独立设置；进度动画只改宽度。不要直接把 `Loss.Size=Fill.Size` 当作同步宽度，否则会覆盖 Loss 自己的高度。

```lua
-- 仅同步真实进度的宽度，保留损失层在预制体中设置的高度。
local fillWidth = fill.Size.X
loss.Size = UDim2.new(fillWidth.Scale, fillWidth.Offset, loss.Size.Y.Scale, loss.Size.Y.Offset)
```

Tween 目标同样保留目标条自己的 `Size.Y`，重置时只将 X 归零。三条不加固定宽高比约束；约束放在整个大区域。高度较小时，它们仍由共同的垂直中心线对齐。

使用不透明矩形填充，否则下层完整宽度的 Loss／Settling 可能从 Fill 的透明装饰中透出。允许各条有不同高度，但其上下可见边缘应符合设计。检查实际 `ZIndexBehavior` 和嵌套层级，不能只比较几个 ZIndex 数字。

## 沿用动作事件进行收束

前提：业务已经提供动作开始／结束事件，HP 在动作期间单调减少，Fill 代表当前剩余量。回血、重置或双向变化不适用下面的原样流程，需先核实项目已有语义。

| 时机 | 表现处理 |
|---|---|
| Begin | 刷新真实 HP 对应的 Fill；将 Fill 的 X 复制到 Loss。上一段 Settling 继续播放。 |
| 动作期间扣血 | 更新 Fill 与读数，Loss 保持本套起点。 |
| 匹配的 End | 刷新 Fill；取消旧 Settling Tween；Settling 的 X 取 Loss 的 X；Loss 的 X 取 Fill 的 X；Settling Tween 到当前 Fill 的 X。 |
| 退出／新回合重置 | 结束收束动画，清掉动作快照并隐藏／归零残血层宽度，保留各层高度。 |

- 所有同步和 Tween 均只改变 X，不计算“损失段的起点 Position＋差量宽度”。
- 沿用当前动作配对和已确认收束时长，不创建重复动作状态，也不默认新增固定等待。
- 先核实 Begin 位于首击前、End 位于本套最后一次 HP 提交后。HP 和 End 可在同一调用链内变化；权威值已经提交时，采样前刷新 Fill 才能取得最新宽度。若 End 早于 HP 提交，应核查现有提交完成通知或在批准范围内修正顺序，不能声称刷新本身就能取得未来的值，也不要随意延迟 End 导致它与下一次 Begin 错序。
- 取消的旧 Tween 完成回调不能隐藏新的收束层；使用项目已有取消／完成状态处理。新 Begin 仅更新 Loss，不取消上一段 Settling。
- 无损失、归零和隐藏状态按实际宽度与现有规则处理，避免留下静止的全长残血层。

## 验收重点

- 满值、中间值、极低值、零值：槽底是否正确，斜角和矩形外沿是否漏色。
- 同时显示三层，设置不同高度：位置始终固定，宽度更新与退出重置均保留各自 Y。
- 连续动作：上一段收束与新 Loss 能同时存在；新的 End 正确替换旧收束。
- 同步致命扣血：End 不读取旧 Fill 宽度，零值后无残留。
- 槽内闪光／流光位于实际开口范围，未被面板整段遮住；槽外爆点按设计保留可见区域。
- 在代表性屏幕比例中重复检查，防止素材留白、约束或裁切导致内部布局偏移。
